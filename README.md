## 📖 项目简介

**小简攒钱打卡** 是一个面向年轻用户的攒钱目标管理微信小程序，核心不是“记账”，而是“帮用户坚持存钱”。

它聚焦一个非常明确的产品方向：

- 让用户更容易开始第一笔攒钱
- 让用户知道今天该存多少、下一步该做什么
- 让用户在连续打卡中获得越来越强的反馈和成就感
- 用更精致、更有氛围感的界面提升停留和回访意愿

- ✨ **极简至上**：单页面完成核心操作，打开即用，几秒完成记录
- 🔒 **隐私安全**：所有数据 100% 存储在用户本地，不上传服务器
- 🎨 **颜值在线**：奶油纸感 + 轻玻璃拟态 + 情绪化渐变背景
- 🏆 **成就系统**：自动解锁成就，持续给用户正向反馈
- 📸 **分享裂变**：一键生成精美海报，支持分享到朋友圈/小红书
- ✅ **完全合规**：严格遵循微信个人开发者审核规范，无金融敏感内容

## 🎯 核心功能

### 基础功能
- [x] **热门目标模板** - 预置 8 个高频攒钱目标，点击后带模板进入创建流程
- [x] **自定义目标创建** - 支持输入目标名称、金额、截止日期
- [x] **攒钱模式选择** - 支持自由攒、365 天、52 周、每月定存
- [x] **编辑目标** - 随时修改目标信息，不用删除重建
- [x] **删除目标** - 支持删除不需要的目标
- [x] **删除历史联动清理** - 删除目标时同步清理对应打卡记录
- [x] **每日打卡记录** - 快捷金额按钮+自定义输入，记录只需要 3 秒
- [x] **进度可视化** - 进度条颜色根据进度自动变化（蓝→橙→绿→金）
- [x] **剩余天数显示** - 直观看到目标截止还有多少天
- [x] **历史记录查看** - 每个目标可查看所有打卡记录

### 养成系特色
- [x] **成就系统** - 7 个预设成就，满足条件自动解锁
- [x] **目标完成庆祝动画** - 弹框庆祝，给足仪式感
- [x] **已完成自动归档** - 未完成在前，已完成在后，金色徽章标记
- [x] **连续打卡统计** - 自动计算连续打卡天数，断签自动重置
- [x] **今日行动卡** - 自动聚焦当前最值得推进的目标，告诉用户今天该做什么
- [x] **建议金额提示** - 根据目标金额和截止日期给出今天建议存入金额
- [x] **里程碑反馈** - 告诉用户再攒多少可以到 25% / 50% / 75% / 100%
- [x] **一键填入建议金额** - 打卡弹窗可直接使用建议金额，减少输入成本
- [x] **最近 28 天节奏板** - 可视化最近打卡节奏，强化“不要断”的心理反馈

### 数据统计
- 总攒钱金额 & 总目标进度
- 今日已攒金额
- 本月新增攒钱
- 连续打卡天数
- 累计打卡次数
- 已完成目标数
- 日均攒钱
- 最近 28 天攒钱活跃天数

### 分享裂变
- [x] 一键生成 9:16 高颜值分享海报
- [x] 海报包含目标进度、连续打卡、励志文案
- [x] 支持保存到相册分享

## 🎨 设计特色

### 色彩系统
- 背景：奶油纸感渐变（暖米色 → 轻雾白 → 冷静灰蓝）
- 主色：青绿色 `#1E7F74`
- 强调色：暖橙色 `#F08A5D`
- 文字：深灰蓝 `#22313F`
- 进度条颜色根据进度自动变化：
  - 0-30%：蓝色 `#2196F3`
  - 30-80%：橙色 `#FF9800`
  - 80-100%：绿色 `#4CAF50`
  - 100%：金色 `#FFD700`

### 设计原则
- 轻玻璃拟态 + 杂志感分层布局，避免“工具页过于死板”
- 单页面设计，所有操作通过底部弹窗完成，无二级跳转
- 情感化设计，通过成就、庆祝动画、节奏板和里程碑给用户正向反馈
- 首页优先展示“今天该做什么”，而不是堆积信息
- 严格遵循微信个人开发者合规要求

## 💡 产品定位

- **目标用户**：18-35 岁年轻用户（学生、职场新人、宝妈）
- **核心痛点**：
  - 记账软件太繁琐，要记每一笔花销，坚持不下来
  - 攒钱没有正向反馈，攒着攒着就放弃了
  - 市面上同类工具全是强制广告，体验很差
  - 功能太复杂，只想简单记个攒钱

- **解决方案**：极简操作 + 明确的今日动作 + 正向反馈 + 无强制广告
- **产品一句话**：不是帮用户管钱，而是帮用户坚持存钱。
