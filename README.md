## 📖 项目简介

**小简攒钱打卡** 是一个面向年轻用户的极简攒钱目标管理微信小程序，主打养成系打卡、正向反馈、高颜值分享海报。

- ✨ **极简至上**：单页面完成所有操作，打开即用，10 秒完成记录
- 🔒 **隐私安全**：所有数据 100% 存储在用户本地，不上传服务器
- 🎨 **颜值在线**：玻璃拟态+水彩渐变设计，符合女性用户审美
- 🏆 **成就系统**：自动解锁成就，持续给用户正向反馈
- 📸 **分享裂变**：一键生成精美海报，支持分享到朋友圈/小红书
- ✅ **完全合规**：严格遵循微信个人开发者审核规范，无金融敏感内容

## 🎯 核心功能

### 基础功能
- [x] **热门目标一键添加** - 预置 8 个高频攒钱目标，点击直接创建
- [x] **自定义目标创建** - 支持输入目标名称、金额、截止日期
- [x] **编辑目标** - 随时修改目标信息，不用删除重建
- [x] **删除目标** - 支持删除不需要的目标
- [x] **每日打卡记录** - 快捷金额按钮+自定义输入，记录只需要 3 秒
- [x] **进度可视化** - 进度条颜色根据进度自动变化（蓝→橙→绿→金）
- [x] **剩余天数显示** - 直观看到目标截止还有多少天
- [x] **历史记录查看** - 每个目标可查看所有打卡记录

### 养成系特色
- [x] **成就系统** - 7 个预设成就，满足条件自动解锁
- [x] **目标完成庆祝动画** - 弹框庆祝，给足仪式感
- [x] **已完成自动归档** - 未完成在前，已完成在后，金色徽章标记
- [x] **连续打卡统计** - 自动计算连续打卡天数，断签自动重置

### 数据统计
- 总攒钱金额 & 总目标进度
- 本月新增攒钱
- 连续打卡天数
- **累计打卡次数** - 新增
- **已完成目标数** - 新增
- 日均攒钱

### 分享裂变
- [x] 一键生成 9:16 高颜值分享海报
- [x] 海报包含目标进度、连续打卡、励志文案
- [x] 支持保存到相册分享

## 🎨 设计特色

### 色彩系统
- 背景：极光渐变（晨曦粉 → 极光蓝 → 奶油白）
- 核心数据：玫瑰桃粉 `#FF7E79`
- 文字：暖咖色 `#5A4A42`
- 进度条颜色根据进度自动变化：
  - 0-30%：蓝色 `#2196F3`
  - 30-80%：橙色 `#FF9800`
  - 80-100%：绿色 `#4CAF50`
  - 100%：金色 `#FFD700`

### 设计原则
- 玻璃拟态风格，氛围感+温度感
- 单页面设计，所有操作通过底部弹窗完成，无二级跳转
- 情感化设计，通过成就、庆祝动画给用户正向反馈
- 严格遵循微信个人开发者合规要求

## 🏁 合规说明

- ✅ 广告完全合规（流量主），无强制广告

## 💡 产品定位

- **目标用户**：18-35 岁年轻用户（学生、职场新人、宝妈）
- **核心痛点**：
  - 记账软件太繁琐，要记每一笔花销，坚持不下来
  - 攒钱没有正向反馈，攒着攒着就放弃了
  - 市面上同类工具全是强制广告，体验很差
  - 功能太复杂，只想简单记个攒钱

- **解决方案**：极简操作 + 正向反馈 + 无强制广告
